# SCOPE Project Docs

Use these files by priority:

1. `PROJECT.md`: installed as platform project instructions.
2. `LLM-CONTEXT.md`: current reviewer and implementation-agent context.
3. `*-DESIGN.md`: design records for current or recently completed architecture.
4. `*-IMPLEMENTATION-PLAN.md` and `*-PLAN.md`: historical execution plans.

Historical plans may mention old file paths, removed test names, or completed migration steps. Treat them as decision history only. Current source files, agent prompts, schemas, and tests are authoritative.
