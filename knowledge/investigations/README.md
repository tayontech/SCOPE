# Investigation Records

Store completed `scope-investigate` records here.

Each investigation should use YAML frontmatter for filtering:

```yaml
---
id: INV-0001
date: YYYY-MM-DD
status: confirmed|likely_normal|suspicious|false_positive|coverage_gap|needs_review
account_id: "123456789012"
entities: []
ttps: []
data_sources: []
---
```

Investigation records should include hypothesis, queries, evidence timeline, disposition, lessons, and knowledge updates applied.
